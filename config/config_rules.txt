Значения опций в .config (OpenWrt / Kconfig)
============================================

1. =y — встроить в прошивку
   Пакет попадает в образ прошивки (rootfs) и доступен сразу после загрузки.
   Для опций ядра — код собирается прямо в ядро.

     CONFIG_PACKAGE_luci=y


2. =m — собрать отдельным пакетом, но НЕ класть в прошивку
   Пакет компилируется и появляется в bin/packages/..., его можно поставить
   позже через apk/opkg. В образ прошивки он не входит.
   Для kmod-пакетов это тоже значит «отдельный пакет», а не «модуль, который
   будет лежать в /lib/modules»: в /lib/modules он попадёт только после установки.

     CONFIG_PACKAGE_kmod-ath9k=m


3. Отключено — не собирается вообще
   Каноническая запись (так её пишет make menuconfig / make defconfig):

     # CONFIG_PACKAGE_kmod-bluetooth is not set

   Запись CONFIG_PACKAGE_kmod-bluetooth=n парсер тоже принимает, но после
   make defconfig она превращается в строку выше.

   ВАЖНО: «is not set» не запрещает пакет жёстко. Если другой включённый пакет
   зависит от него (DEPENDS/select), make defconfig включит его обратно.
   А если строку пакета просто удалить из .config, make defconfig подставит
   значение по умолчанию (для пакетов из DEFAULT_PACKAGES / DEVICE_PACKAGES — =y).


4. Числа и строки
   Числовые и строковые опции задаются значением:

     CONFIG_TARGET_ROOTFS_PARTSIZE=512
     CONFIG_TARGET_ARCH_PACKAGES="aarch64_generic"


Пример фрагмента .config
------------------------

     CONFIG_PACKAGE_luci=y
     CONFIG_PACKAGE_kmod-ath9k=m
     # CONFIG_PACKAGE_kmod-bluetooth is not set

Комментарий в конце строки со значением (CONFIG_X=y  # текст) Kconfig
не поддерживает — комментарии пишутся только отдельной строкой, начиная с #.
